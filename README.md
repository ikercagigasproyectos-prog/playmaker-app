# Playmaker para Android

Descarga directa de la app de Playmaker para móviles Android.

**[Descargar playmaker.apk](https://github.com/ikercagigasproyectos-prog/playmaker-app/releases/download/android-latest/playmaker.apk)**

Al instalarla, Android puede pedir permiso para instalar apps de fuera de Google Play: acéptalo para este archivo.

La app abre siempre la versión más reciente de Playmaker, así que no hace falta actualizarla cada vez.
